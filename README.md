# Модули Сойки

Каталог модулей для [Сойки](https://github.com/zfd430792-coder/soika) и
руководство, как их писать.

Модуль отсюда ставится одной командой:

```
.ml counter
```

Всё базовое у Сойки **встроено** — 14 модулей и 46 команд работают сразу после
входа. Сюда складывается необязательное: примеры, шаблоны и то, что нужно не
всем.

| Модуль | Команды | Зачем |
|---|---|---|
| `template.py` | `.template` | пустой скелет — с него начинают свой модуль |
| `counter.py` | `.count`, `.counts`, `.delcount` | живой пример: база, кнопки, конфиг |

## Как сюда попасть

Свой модуль можно предложить пул-реквестом: один `.py` файл в корень, рабочий и
по чек-листу ниже. Или держи модули у себя — `.cfg` → **Загрузчик** → `repo`
переключает `.ml` на любой другой репозиторий.

## Модуль за пять минут

Модуль — это один `.py` файл с классом, унаследованным от `loader.Module`:

```python
from .. import loader, utils


@loader.tds
class ПриветМод(loader.Module):
    """Здоровается — эта строка видна в .help"""

    strings = {
        "name": "Привет",
        "hello": "👋 <b>Привет, {}!</b>",
    }

    @loader.command(alias="пр")
    async def hellocmd(self, message):
        """[имя] — поздороваться"""
        name = utils.get_args_raw(message) or "мир"
        await utils.answer(message, self.strings["hello"].format(utils.escape_html(name)))
```

Отправь этот файл в любой чат и ответь на него `.loadmod` — появится команда
`.hello`. Всё, модуль готов.

Что здесь есть и зачем:

- `@loader.tds` — метка, что докстроки переводимые. Ставится всегда;
- докстрока класса — описание модуля в `.help`;
- `strings["name"]` — как модуль называется в списке. Без него будет имя класса;
- метод, чьё имя кончается на `cmd`, становится командой: `hellocmd` → `.hello`;
- докстрока метода — справка по команде в `.help <модуль>`.

## Шапка файла

Перед импортами можно положить метаданные — Сойка их прочитает:

```python
# meta developer: @username
# meta description: Короткое описание для каталога
# meta banner: https://example.com/banner.png
# requires: aiohttp pillow
```

- `developer` — автор, показывается в `.help <модуль>`;
- `banner` (или `pic`) — картинка над справкой и над карточкой установки.
  Годится `.png`, `.jpg`, `.gif`, `.mp4`;
- `description` — строка для каталога;
- `requires` — пакеты, которых может не быть. Сойка поставит их через pip сама,
  до первого запуска модуля.

## Тексты и переводы

Все видимые строки держи в `strings`, а не в коде — тогда их можно перевести и
поменять, не трогая логику.

```python
    strings = {
        "name": "Погода",
        "loading": "🌦 <b>Смотрю прогноз...</b>",
        "result": "🌦 <b>{city}:</b> {temp}°",
        "failed": "🚫 <b>Не отвечает сервис погоды</b>",
    }

    strings_en = {
        "loading": "🌦 <b>Checking the forecast...</b>",
        "result": "🌦 <b>{city}:</b> {temp}°",
        "failed": "🚫 <b>Weather service is down</b>",
    }
```

`strings_en` заполняется по желанию: чего в нём нет, возьмётся из `strings`.
Язык переключается командой `.lang` и кнопкой в меню бота.

Разметка — HTML: `<b>`, `<i>`, `<code>`, `<pre>`, `<a href="">`. Всё, что
пришло от пользователя, прогоняй через `utils.escape_html()`, иначе одна угловая
скобка сломает сообщение.

## Команды

Метод становится командой двумя способами:

```python
    @loader.command()                      # .name
    async def namecmd(self, message): ...

    @loader.command(alias="п")             # .name и .п
    async def namecmd(self, message): ...

    @loader.command(aliases=["п", "name2"])  # несколько имён
    async def namecmd(self, message): ...
```

Суффикс `cmd` в имени метода отрезается — он и определяет имя команды. Метод без
`cmd` и без декоратора командой не станет: служебные методы называй с
подчёркивания (`_helper`), их Сойка не трогает.

Докстрока метода — это справка. Пиши её в формате «аргументы — что делает»:

```python
    @loader.command()
    async def weathercmd(self, message):
        """<город> — прогноз погоды"""
```

## Как отвечать

```python
await utils.answer(message, "текст")                       # правит своё сообщение
await utils.answer_file(message, файл, caption="подпись")   # файл или картинка
await utils.answer_with_banner(message, "текст", ссылка)    # картинка с подписью
```

`utils.answer` — основной способ. Если команду позвал ты сам, он **редактирует**
твоё же сообщение, а не плодит новые; если позвал кто-то другой — отвечает
отдельным сообщением. Длинный текст режется по границам сам.

Возвращает отправленное сообщение — его можно править дальше:

```python
        sent = await utils.answer(message, self.strings["loading"])
        данные = await долгая_работа()
        await utils.answer(sent, self.strings["result"].format(**данные))
```

## Аргументы

```python
utils.get_args_raw(message)            # всё после команды одной строкой
utils.get_args(message)                # список, кавычки уважаются
utils.get_args_split_by(message, ",")  # разбить по своему разделителю
utils.get_args_html(message)           # с сохранением разметки
utils.get_kwargs(message)              # ключ=значение → словарь
await utils.get_target_user(message)   # юзер из реплая, @ника или id
```

Проверяй аргументы до работы и объясняй, чего не хватает:

```python
        if not (args := utils.get_args_raw(message)):
            prefix = self.client.dispatcher.prefixes[0]
            await utils.answer(message, self.strings["usage"].format(prefix))
            return
```

## Настройки

Всё, что пользователь захочет поменять, выноси в конфиг — его правят кнопками
через `.cfg`, а не редактированием файла.

```python
    config = loader.ModuleConfig(
        loader.ConfigValue(
            "city",                                   # ключ
            "Москва",                                 # значение по умолчанию
            "Город по умолчанию",                     # описание в .cfg
            validator=loader.validators.String(max_len=64),
        ),
        loader.ConfigValue(
            "units",
            "metric",
            "Единицы измерения",
            validator=loader.validators.Choice(["metric", "imperial"]),
        ),
    )
```

Читается как словарь: `self.config["city"]`.

Валидаторы: `Boolean`, `Integer(minimum=, maximum=)`, `Float`, `String(max_len=)`,
`RegExp`, `Choice`, `MultiChoice`, `Series`, `Link`, `TelegramID`, `Emoji`,
`Hidden` (прячет значение в редакторе), `NoneType`, `Union`.

Пустое значение разрешают так:

```python
            validator=loader.validators.Union(
                loader.validators.NoneType(),
                loader.validators.Link(),
            ),
```

Когда настройки поменяли, вызывается `config_complete()` — там перечитывают то,
что зависит от конфига.

## Своя память в базе

У модуля своя секция в базе, называется по имени класса:

```python
        self.set("last_run", time.time())     # записать
        self.get("last_run", 0)               # прочитать со значением по умолчанию
        счётчики = self.pointer("counters", {})   # живой словарь: правки сохранятся сами
```

`pointer` удобнее для словарей и списков: меняешь объект — база сохраняется без
дополнительного `set`. Класть можно только то, что переживает JSON: строки,
числа, списки, словари.

## Права

По умолчанию команда доступна владельцу и списку `.sudo`. Расширяется
декораторами:

```python
    @loader.owner          # только владелец
    @loader.sudo           # владелец и sudo
    @loader.group_admin    # админы чата
    @loader.group_member   # любой участник чата
    @loader.pm             # любой, кто пишет в личку
    @loader.everyone       # вообще все
    @loader.command()
    async def somecmd(self, message): ...
```

Декоратор прав ставится **над** `@loader.command()`. Владелец может переопределить
права любой команды через `.security`, и его выбор важнее написанного в коде.

Опасные вещи (выполнение кода, доступ к файлам, деньги) закрывай `@loader.owner`
явно, даже если и так по умолчанию.

## Вотчеры и фильтры

Вотчер смотрит на все сообщения подряд:

```python
    @loader.watcher(only_pm=True, no_commands=True)
    async def watcher(self, message):
        """Реагирует на входящие в личке"""
```

Фильтры пишутся прямо в декораторе: `out`, `in`, `only_pm`, `no_pm`,
`only_chats`, `only_groups`, `only_channels`, `only_media`, `no_media`,
`no_forwards`, `no_stickers`, `no_docs`, `no_inline`, `no_commands`,
`only_commands`. Ещё есть `startswith=`, `endswith=`, `contains=`, `regex=`,
`chat_id=`, `from_id=`.

Вотчер не должен падать и не должен быть медленным: он вызывается на каждое
сообщение. Тяжёлое уноси в `utils.spawn(...)`.

## Кнопки, галереи, списки

Всё это работает через собственного инлайн-бота:

```python
        await self.inline.form(
            "🔢 <b>Счётчик: 0</b>",
            message=message,
            reply_markup=[
                [
                    {"text": "➖", "callback": self._change, "args": (-1,)},
                    {"text": "➕", "callback": self._change, "args": (1,)},
                ],
                [{"text": "🌐 Сайт", "url": "https://example.com"}],
            ],
        )

    async def _change(self, call, шаг: int):
        await call.answer("готово")                 # всплывашка на кнопке
        await call.edit("новый текст", reply_markup=[...])   # переписать сообщение
```

Виды кнопок: `callback` (вызвать метод), `url` (ссылка), `input` (подставить
текст в поле ввода), `data` (сырой callback_data).

Ещё есть галерея и постраничный список:

```python
        await self.inline.gallery(message, ["ссылка1", "ссылка2"])
        await self.inline.list(message, ["страница 1", "страница 2"])
```

Бот может быть не поднят — проверяй и делай запасной путь:

```python
        if self.inline is not None and self.inline.init_complete:
            if await self.inline.form(...):
                return

        await utils.answer(message, "то же самое текстом")
```

## Фоновые задачи

```python
    @loader.loop(interval=60, autostart=True, wait_before=True)
    async def checker(self):
        ...
```

- `interval` — пауза между запусками, секунд;
- `autostart` — стартовать при загрузке модуля;
- `wait_before` — сначала подождать, потом работать (иначе наоборот);
- `stop_clause="ключ"` — цикл остановится, когда в базе появится этот ключ.

Выйти из цикла изнутри — `raise loader.StopLoop`. Исключения внутри цикла Сойка
ловит и пишет в лог, но цикл не умирает — лучше ловить самому.

---

## Жизненный цикл

```python
    async def client_ready(self, client, db):
        """Модуль загружен, клиент на связи — здесь доинициализируемся"""

    async def on_dlmod(self):
        """Один раз сразу после установки через .dlmod / .loadmod"""

    async def on_unload(self):
        """Модуль выгружают — закрой сессии, погаси задачи"""

    async def config_complete(self):
        """Настройки применены, в том числе после правки через .cfg"""
```

Внутри модуля доступны: `self.client` (Telethon), `self.db` (база),
`self.inline` (бот), `self.allmodules` (реестр модулей), `self.tg_id` (свой id),
`self.lookup("Имя")` (другой модуль).

Если модуль понял, что работать не может:

```python
        raise loader.SelfUnload("Нужен ключ API — добавь его в .cfg")
        raise loader.SelfSuspend("Сервис недоступен, попробую после перезапуска")
        raise loader.LoadError("Модуль не для этой версии")
```

## Зависимости и библиотеки

Пакеты — строкой `# requires:` в шапке, Сойка поставит их сама.

Общий код для нескольких модулей выносят в библиотеку:

```python
        lib = await self.import_lib("https://example.com/lib.py")
```

Библиотека — файл с классом-наследником `loader.Library`; повторный импорт по
той же ссылке отдаёт уже загруженный объект.

## Отладка

```
.loadmod            установить .py файл (ответом на него)
.dlmod <ссылка>     поставить по ссылке
.ml <имя>           поставить из этого каталога
.unloadmod <имя>    выгрузить
.modules            что установлено и откуда
.logs error         лог ошибок файлом
.e <код>            выполнить Python прямо в чате
```

В `.e` доступны `client`, `db`, `self`, `utils`, `loader`, `modules`, `message`,
`reply` — удобно проверить кусок кода, не переустанавливая модуль.

Если команда падает, Сойка присылает трейсбек в чат — читай его целиком, там
видно и файл, и строку.

## Как правильно — чек-лист

1. **Один файл — один модуль.** Класс, унаследованный от `loader.Module`.
2. **Тексты в `strings`**, не в коде. Английский по возможности.
3. **HTML экранируй.** Всё пользовательское — через `utils.escape_html`.
4. **Отвечай через `utils.answer`**, а не `client.send_message`.
5. **Настройки в конфиг** с валидатором, а не константами в коде.
6. **Состояние в базу** через `self.get/set/pointer`, а не в переменные класса.
7. **Долгое — с промежуточным сообщением**: «работаю…» → результат.
8. **Опасное — под `@loader.owner`.**
9. **Служебные методы с подчёркивания**, чтобы не стать командой случайно.
10. **Проверяй инлайн-бота** перед кнопками и держи текстовый запасной путь.
11. **Гаси задачи и сессии** в `on_unload`.
12. **Ошибки лови сам** и объясняй пользователю, что не так и что делать.

## Частые ошибки

**Команда не появилась.** Метод не кончается на `cmd` или начинается с
подчёркивания. Либо файл не загрузился — смотри `.logs error`.

**`Команда .x уже занята модулем Y`.** Два модуля с одинаковым именем команды:
последний перебивает первого. Переименуй свою команду или выгрузи чужой модуль.

**Сообщение приходит без разметки или обрывается.** В тексте есть `<` или `>` из
пользовательских данных — забыл `escape_html`.

**Кнопки не появились.** Инлайн-бот не поднялся: `.botinfo` покажет состояние,
`.logs error` — причину. Всегда делай запасной вывод текстом.

**Модуль пропал после перезапуска.** Он выгрузил себя сам через `SelfUnload` или
упал при загрузке — причина в логе.

**`ModuleNotFoundError` при установке.** Не указан `# requires:` с нужным
пакетом.

**Настройка не применяется.** Значение прочитано один раз при загрузке — читай
`self.config["ключ"]` там, где оно используется, или обновляй в
`config_complete`.

## Модули от других юзерботов

Модули, написанные под Hikka, FTG, GeekTG и Dragon, ставятся без правок: слой
совместимости подменяет им имена пакетов на лету — `hikkatl` → `telethon`,
`hikka` → `soika`. Если чужой модуль всё-таки не пошёл, смотри `.logs error`:
чаще всего дело в пакете, которого нет в системе.

## Свой каталог

Команда `.ml` берёт файлы отсюда, но каталог можно поменять на свой:
`.cfg` → **Загрузчик** → `repo`. Указываешь адрес вида
`https://raw.githubusercontent.com/пользователь/репозиторий/main`, кладёшь туда
`.py` файлы — и они ставятся командой `.ml имя`.
